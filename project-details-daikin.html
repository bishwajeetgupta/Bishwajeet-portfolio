Overview

Daikin RMS is an internal management system for tracking service units, requests, and maintenance history. The dashboard needed to present dense operational data clearly enough for staff to scan and act on quickly.

With a data-heavy internal tool like this, the design work was less about visual flourish and more about information hierarchy — making sure the most actionable data (open requests, SLA status) surfaced first.

  • Data-dense dashboard UI
  • Service & maintenance tracking
  • Open requests & SLA status first
  • Consistent status tags for fast scanning

Design system

I set up a compact type scale and consistent tag styling for statuses such as Scheduled, Review, and OK, so staff can scan dozens of rows at a glance without the interface feeling cluttered. The same components carry across the web dashboard and the mobile views.

  • Data table, status tag and KPI card components
  • Compact type scale for dense data
  • Consistent styling across web and mobile

Challenges & solutions

Challenge: The dashboard had to show dense operational data, and staff needed to scan open requests and SLA status quickly. Too much detail at once would slow them down and hide the items that needed action first.

Solution: I set a clear information hierarchy that pushed the most actionable data to the top, used calm and consistent status colors, and kept the layout easy to scan. Staff could then read the state of the system and act in seconds.

Conclusion

Implementing the dashboard directly in HTML kept the handoff simple for a smaller-scope internal tool, while still following the same component discipline used on larger projects.

The result is a dashboard that surfaces what needs attention first, which matters more for an internal ops tool than any amount of visual polish.
