Overview

This is an AI-driven hotel operations platform that automates property tracking, inspections, maintenance workflows, task scheduling, cleaning operations, safety audits, asset monitoring, and incident reporting — used across housekeeping, maintenance, supervisor, and management roles.

The core challenge was designing one system that serves four very different daily workflows: supervisors need oversight dashboards, while housekeeping and maintenance staff need a fast, mobile-first way to update task status from the field, often between rooms with limited time.

  • Multi-role, role-based workflows
  • Mobile-first field interfaces
  • AI-driven SaaS product
  • Hospitality operations

Design system

I built a shared design system so the web dashboard and the mobile field app use the same components and visual language. The mobile side uses larger tap targets and shorter labels, since staff are moving between tasks rather than sitting at a desk.

  • Task card, status tag and checklist components
  • Shared colours, type and spacing
  • One consistent system across web and mobile

Challenges & solutions

Challenge: One system had to serve four very different daily workflows. Supervisors needed oversight dashboards, while housekeeping and maintenance staff needed a fast, mobile-first way to update task status from the field, often between rooms with very little time.

Solution: I separated the views by role but built every screen from the same component library. Supervisors kept the oversight they needed, and field staff got a quick, mobile-first flow to update status with fewer taps, so no group felt the tool was built for someone else.

Conclusion

Separating dashboard views by role, while keeping every screen built from the same component library, let supervisors get the oversight they needed without slowing down the staff actually doing the work on the ground.

The mobile task interface in particular focused on minimizing taps to complete — a small detail that matters a lot when someone is holding cleaning supplies in one hand and a phone in the other.
