Overview

This is a set of 6 website UI designs I created for different clients and brands. Each site was designed in Figma, page by page, with a clear layout, a strong first screen, and a simple path for visitors to reach the key action.

The work covered the full design of each website, from the home page to inner pages. Every layout was built for desktop first and then adjusted for tablet and mobile, so the content order and spacing still work on small screens.

  • 6 full website UI designs

Approach

Each brand had a different look, so the challenge was to give every site its own feel while keeping the same care for layout, spacing, and readability. Visitors needed to understand what the brand offers within the first screen.

I started each design from the home page, set the type and spacing scale, then designed the inner pages on the same grid. This kept every site clean and easy to scan, and made the handoff to build straightforward.

Conclusion

Across all 6 websites, the goal was the same: a clear first screen, an easy path through the pages, and a design that fits the brand.

Each design is responsive and built on a consistent grid, so the sites read well on desktop, tablet, and mobile.
