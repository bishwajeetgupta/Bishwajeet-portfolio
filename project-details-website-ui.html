Overview

This is a set of 6 website UI designs that I created for different clients and brands. I designed each site in Figma, page by page. Each one has a clear layout, a strong first screen and a simple path for visitors to reach the key action.

The work covered the full design of each website, from the home page to the inner pages. Every layout was designed for desktop first and then adjusted for tablet and mobile. This way, the content order and spacing still work on small screens.

  • 6 full website UI designs
  • A clear layout with a strong first screen
  • Responsive layouts for desktop, tablet and mobile
  • Consistent type, spacing and calls to action

Approach

Each brand had a different look. The challenge was to give every site its own feel while keeping the same care for layout, spacing and readability. Visitors needed to understand what the brand offers within the first screen.

I started each design with the home page and set the type and spacing scale. Then I designed the inner pages on the same grid. This kept every site clean and easy to scan, and it made the handoff to development simple.

Conclusion

Across all 6 websites, the goal was the same: a clear first screen, an easy path through the pages and a design that fits the brand.

Each design is responsive and built on a consistent grid, so the sites read well on desktop, tablet and mobile.
